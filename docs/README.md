# Documentación de entrega final

Este directorio reúne la documentación técnica y de usuario del proyecto TC-DIAG.

## Contenido

- [Manual de usuario](Manual_Usuario.md): cómo ejecutar la API, usar el dashboard y consumir los endpoints.
- [Manual técnico](Manual_Tecnico.md): arquitectura, dependencias, variables de entorno, despliegue y pruebas.

## Recomendación para la entrega

1. Incluir el código fuente.
2. Incluir esta carpeta `docs`.
3. Entregar los pesos del modelo como artefacto aparte o mantener la estructura `models/distilbert/` en el entorno de despliegue.
